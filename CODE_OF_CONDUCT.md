# Code of Conduct

Marble Works is a game for kids, and this project should feel as friendly as the game.

- Be kind and patient, especially with people who are new.
- Give feedback about the work, not the person.
- No harassment, insults, or content that isn't suitable for children.

The maintainer may edit or remove comments, issues or pull requests that break these rules, and may block people who keep breaking them. Report problems by opening an issue or contacting the maintainer on GitHub (@Asmo7791).

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org).
