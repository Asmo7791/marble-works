# Privacy

_Last updated: 31 October 2026_

Marble Works is made for children, so it is built to collect nothing.

- **No accounts, ads, analytics or tracking.** The game never sends anything about the player anywhere.
- **Progress stays on the device.** Unlocked levels, best stars and the sound setting are saved in the browser's local storage (or the desktop app's equivalent). Clearing site data or uninstalling the app removes them.
- **No network requests while playing.** Everything the game needs, including fonts, is bundled. After the first visit it runs fully offline.
- **Hosting.** The web version is served by GitHub Pages. GitHub may keep standard server logs (such as IP addresses) as described in the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). The game itself does not read or store them.

Questions: open an issue at https://github.com/Asmo7791/marble-works/issues.
